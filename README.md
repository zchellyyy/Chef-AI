# CHEF-AI

CHEF-AI is an AI-powered web application designed to help users discover recipes and meal ideas based on the ingredients they have available.

## Project Overview

CHEF-AI helps users find possible meals using the ingredients available to them. Instead of wondering what to cook, users can enter their available ingredients and receive recipe suggestions.

The project combines web development and artificial intelligence to create a more convenient and interactive cooking experience.

## Technologies Used

- HTML
- CSS
- JavaScript
- AI Integration

## Features

- Ingredient-based recipe suggestions
- AI-powered meal recommendations
- User-friendly interface
- Recipe and meal discovery
- Interactive user experience
